# 과제 5 공통 사용 상한

이 값은 AI A 시작 전에 확정한다.

AI A와 AI B에 동일하게 적용한다.

## 시간 상한

30분

## 요청 상한

10회

## 요청 횟수 계산 기준

사용자가 AI에게 새로운 작업 지시 메시지를 보내면 1회로 센다.

AI가 내부적으로 실행하는 다음 항목은 요청 횟수에 포함하지 않는다.

- 파일 읽기
- 터미널 명령 실행
- 테스트 실행
- 검색
- 기타 내부 도구 호출

수업에서 별도의 요청/호출 계산 기준을 제시한 경우에는
AI A 시작 전에 이 문서를 수정하고 그 기준을 따른다.

## 중단 규칙

다음 중 하나에 도달하기 전에 작업을 종료해야 한다.

- 실제 작업시간 30분
- 사용자 요청 10회

AI A와 AI B 모두 같은 기준을 사용한다.
