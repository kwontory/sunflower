# Sunflower Project

## 문제

현재 내 위치에서 해를 바라보려면 어느 방향을 봐야 하는지 바로 알기 어렵다.

## 목표

사용자의 현재 위치와 현재 시각을 바탕으로 태양의 위치를 구하고,
사용자가 어느 방향으로 회전해야 해를 바라볼 수 있는지 알려준다.

## 기본 사용자 흐름

1. 사용자가 웹페이지를 연다.
2. 위치 사용을 허용한다.
3. 공개 API에서 태양 관련 데이터를 가져온다.
4. 현재 태양의 방위각과 고도를 표시한다.
5. 가능한 경우 기기의 방향 센서를 읽는다.
6. 사용자가 어느 쪽으로 몇 도 돌아야 하는지 표시한다.

예:

- 오른쪽으로 32° 돌아보세요.
- 왼쪽으로 15° 돌아보세요.
- 지금 해가 정면에 있습니다.

## 과제 4에서 추가할 내용

외부 데이터가 정상일 때뿐 아니라 실패할 때도 상태를 명확하게 표시한다.

예정 기능:

- 공개 API 실제 데이터 표시
- 데이터 출처 표시
- 데이터 조회 시각 표시
- 외부 실패 상황 재현
- 마지막 정상값 보존
- KST 기준 일별 기록
- 서로 다른 날짜의 기록 비교

## 과제 5

과제 4가 완성된 이후 작은 개선 하나를 고른다.

그 시점에:

- 고정 검사 정확히 10개
- 공통 작업 시간 제한
- 공통 요청/호출 제한

을 정한다.

과제 5용 값은 현재 단계에서 확정하지 않는다.

## 현재 상태

기획만 완료.

공개 API는 확정했다. (D003, D004)

- 주 API: USNO celnav (태양 방위각·고도)
- 교차 검증용: NASA JPL Horizons (필요할 때만)
- 외부 API 호출 횟수는 최대한 줄인다.

아직 기술 스택과 UI 구조는 최종 확정되지 않았다.
