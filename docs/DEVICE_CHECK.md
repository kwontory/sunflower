# 실기기 확인 (T13)

휴대폰·태블릿에서 위치와 방향 센서가 실제로 동작하는지 확인한다.
위치·방향 센서는 HTTPS에서만 동작하므로 Vercel 배포 주소로 접속한다 (D008).

## 접속

- 배포 주소: Vercel 대시보드의 `sunflower` 프로젝트에서 확인한다.
- 현재 배포에는 Vercel 로그인 보호(Deployment Protection)가 켜져 있다.
  기기 브라우저에서 Vercel 계정으로 로그인하면 열린다.

## 개인정보 주의

- 실제 위치에서 확인하되, **화면 캡처·녹화를 저장소(`evidence/` 포함)에 올리지 않는다.**
  해의 방위각·고도와 시각을 함께 보면 대략의 지역을 역산할 수 있다.
- "기록 내보내기" JSON에는 반올림 좌표(약 1.1km 단위)가 들어 있으므로 저장소에 올리지 않는다.
- 저장소에 남길 증거가 필요하면 테스트용 공개 좌표로 만든 결과만 쓴다 (T14).

## 확인 항목

기기마다 결과 칸에 `통과` / `실패 (내용)` / `해당 없음`을 적는다.

## 발견한 문제와 조치

### 1차 확인 (2026-09-27, 휴대폰)

| 내용 | 결과 | 조치 |
|---|---|---|
| 위치 권한 허용 후 화면이 바뀌지 않아 직접 새로고침해야 함 | 실패 | 권한 변경 감지 후 재요청, 화면 복귀 시 재요청, 제한 시간 20초 (T16) |
| 다이얼이 휙휙 움직여 불안정 | 실패 | 제자리 갱신 + 회전 애니메이션 + 떨림 보정 (T17) |
| 비행기 모드에서 새로고침 시 화면이 뜨지 않음 | 실패 | 오프라인 캐시(Service Worker) (T18) |
| 휴대폰 가로 화면이 한 화면에 들어오지 않음 | 실패 | 가로 전용 2단 배치 (T19) |
| 위치 권한 거부 시 "방향 감지 안 됨" 표시 | 통과 | - |
| 해의 실제 위치와 일치 여부 | 보류 | 구름으로 확인 불가. 맑은 날 다시 확인 |

| 내용 | 결과 | 조치 |
