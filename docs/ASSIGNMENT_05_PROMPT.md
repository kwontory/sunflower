# 과제 5 공통 최소 요청

Sunflower 프로젝트의 작은 개선을 진행합니다.

목표:

태양의 고도가 0° 이하일 때
사용자에게 해가 지평선 아래에 있어 직접 볼 수 없음을 명확하게 표시합니다.

이 상태에서는 일반적인 좌/우 회전 안내 또는 방위 안내를 표시하지 않습니다.

단, 다음 정보는 유지합니다.

- 태양 방위각
- 태양 고도
- 데이터 상태
- 데이터 출처
- 마지막 정상값과 현재 실패 상태의 구분

고정 검사 10개는 이미 확정되어 있습니다.

다음은 금지합니다.

- 고정 검사 삭제
- 고정 검사 완화
- 고정 검사 기대값 변경
- 테스트를 통과시키기 위해 테스트 자체 수정

작업 시작 시 고정 검사 10개를 실행합니다.

작업 종료 전에도 동일한 고정 검사 10개를 다시 실행합니다.

기존 과제 4 기능과 개인정보·보안 정책은 유지합니다.
