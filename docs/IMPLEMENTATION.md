# 구현 진행 기록

기능 구현을 여러 세션·에이전트가 나눠 진행할 때 중복 작업을 막기 위한 문서다.
새 세션은 `README.md`, `docs/PROJECT.md`, `docs/DECISIONS.md`를 읽은 뒤 이 문서를 읽고,
**"작업 목록"에서 상태가 `대기`인 항목부터** 이어서 진행한다.
작업을 시작하거나 끝내면 이 문서의 상태와 "작업 로그"를 갱신한다.

## 위치 확인 시간 단축 방안 (T22, A+B+C 채택 → D010)

현재 흐름: 위치 요청(`enableHighAccuracy: false`, `maximumAge` 10분, 제한 20초) → 위치를 얻은 뒤에야 USNO 조회.
첫 방문이나 10분 넘게 지난 경우 기기가 위치를 새로 잡아야 해서 수 초~수십 초가 걸리고, 그동안 화면은 "확인 중"에 머문다.

| 안 | 내용 | 효과 | 고려 사항 |
|---|---|---|---|
| A (추천) | 마지막으로 받은 값의 반올림 좌표(약 1.1km)로 먼저 조회·표시하고, 새 위치가 오면 좌표가 다를 때만 다시 조회 | 재방문 시 거의 즉시 표시 | 새로 저장하는 정보 없음(이미 저장된 반올림 좌표 사용). 멀리 이동한 직후 잠깐 이전 지역 값이 보일 수 있어 "위치 확인 중" 표시 필요 |
| B (추천) | `maximumAge`를 10분 → 1시간으로 늘림 | 기기에 남아 있는 위치를 바로 받음 | 수 km 이동해도 해 방향 차이는 0.1° 수준이라 영향 거의 없음 |
| C (추천) | 대기 문구를 단계별로 표시 ("위치를 확인하고 있어요" → "해의 위치를 받아오고 있어요") | 체감 대기 시간 감소, 멈춘 것처럼 보이지 않음 | 화면 문구 추가 |
| D | 첫 방문 제한 시간을 줄이고 실패 시 안내 | 무한 대기처럼 보이는 시간 감소 | GPS를 늦게 잡는 기기에서 실패가 늘 수 있음 |
